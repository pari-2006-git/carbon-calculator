 Carbon Calculator

 Project Overview

Carbon Calculator is a simple and user-friendly web application developed to estimate the carbon footprint generated by daily human activities. The project helps users understand how their electricity consumption, transportation usage, and lifestyle habits contribute to environmental pollution.

This project was created as an educational and practical mini-project to promote awareness about climate change and encourage eco-friendly decisions.

---

 Objectives

- To calculate approximate carbon emissions based on user inputs.
- To spread awareness about reducing carbon footprint.
- To provide a simple and interactive web interface.
- To demonstrate frontend and backend web development skills.

---

 Features

✅ Clean and responsive user interface  
✅ User input form for activity details  
✅ Carbon footprint estimation logic  
✅ Displays calculated emission result  
✅ Easy to use and beginner-friendly project  
✅ Can be enhanced with database integration

 How It Works

1. User opens the Carbon Calculator website.
2. Enters required details such as:
   - Name
   - Electricity usage
   - Transportation distance
3. Clicks submit button.
4. PHP script processes the input data.
5. Carbon footprint result is displayed.
